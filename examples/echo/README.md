# Echo / 残响

Text-only production example. Chinese story and dialogue are intentional; an agent can help translate or adapt them. Read the story bible, scenes, visual locks, refs, shots and music cues together. No images, personal photos, audio or video are included. Referenced assets must be created separately, with your own rights and accurate attribution.

Create a working copy with `python3 tools/new_film.py echo --example echo` from the repository root. Then run the validator. Historical cuts, mixed H3/LTX shots and music filenames illustrate the workflow and need review for a new production. Film link: coming soon.
