# 常见问题

**能一键出片吗？** 不能保证。助手按手册调用现有脚本，故事、选图、试拍与终检仍需决定。通用 CLI 和自动 VLM 审片尚未实现。

**本地要 GPU 吗？** 预期 Colab 流程不用。本机只做剪辑和接收，需 CPU、磁盘和 ffmpeg，权重环境留在云端 /content。

**不用 Box 可以吗？** LTX 等 lab 适配器用外部官方推理仓库；快速 H3 工作机必须有自己的 Box。仓库不带 Box 实现，公开版 GPU 全链路尚未重验。

**三种助手都能用吗？** Claude Code、Codex、Gemini CLI 都读同一手册；生图另有要求，gemini_images.py 实际用 agy。

**为什么没有图和音乐？** 分享的是文字制作文件，不是私人照片或已授权媒体。请自行做参考图、取得音乐许可，原猫照片故意不包含。

**能商用吗？** Apache-2.0 仅覆盖代码，模型、图、配乐和输出发布地区各自核对许可，按要求标注 AI，先读 models.md。

**多少钱？** 没有核实的整片总账。GPU、生图、失败重试和传输都计入预算，排空后仍要确认运行时真的停止计费。

**可以续跑吗？** 保留忽略目录 renders/ 中的回执和租约。重试前核对所有者，H3 和 LTX 不能同时接管一镜；内容变化用版本化镜号或审查后的重拍。

**如何反馈？** 提 issue 附可复现且脱敏的问题，提 PR 修复。不要附令牌、带凭据的 notebook 或私人媒体。见 CONTRIBUTING.md 和 SECURITY.md。
